# POX Hub (`packages/apps/PoxHub`)

<p align="center">
  <b>The central customization dashboard for POX OS</b>
</p>

POX Hub provides deep aesthetic customization for POX OS users:
- **System Themes**: Accent colors, custom fonts, icon shapes.
- **Status Bar**: Custom clock, battery style, signal & Wi-Fi icons.
- **Quick Settings**: Layout customization, tile animations, header styling.
- **Lockscreen**: Clock styles, ambient display customizations.
